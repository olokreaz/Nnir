# NNIR — каталог фильмов и сериалов

Учебный проект: 4 практических работы. Git-репозиторий один, стадии
размечаются тегами.

## Быстрый запуск

```bash
./start.sh
```

Скрипт сам: поднимает группу docker (если сессия её ещё не подхватила),
собирает образ через `docker compose build` и запускает контейнер.
Сайт открывается на http://localhost:8080

Вручную:

```bash
docker compose build
docker compose up -d
```

## Структура проекта

```
it/
├── sites/          # страницы сайта (фронтенд, HTML)
├── assets/         # статические ресурсы (css/, img/ и т.п.)
├── backend/        # серверная часть (ПР3)
├── data/           # данные / внешний источник (ПР2)
├── tools/          # локальные инструменты сборки (не в git)
├── Dockerfile      # образ nginx со статикой
├── docker-compose.yml
├── start.sh        # запуск одной командой
└── .gitignore
```

## Стадии (практические работы)

| Стадия | Описание | Тег | Срок |
|--------|----------|-----|------|
| ПР1 | Страницы сайта: разметка, оформление, навигация | `v1-pr1` | — |
| ПР2 | Моделирование страниц, работа с внешним источником данных | `v2-pr2` | — |
| ПР3 | Сервер и база данных | `v3-pr3` | — |
| ПР4 | Развёртывание приложения | `v4-pr4` | — |

Тег на текущую завершённую стадию: `v1-pr1` уже стоит на master.

## Как отметить следующую стадию

```bash
git add -A
git commit -m "ПР2: ..."
git tag -a v2-pr2 -m "ПР2: ..."
```
